# Timequence

Браузерный редактор таймеров в виде звукового секвенсора. React, TypeScript, Vite, Web Audio API; сервер и аккаунт не нужны.

```sh
npm install
npm run dev -- --port 5173
```

`npm run build` проверяет типы и собирает сайт в `dist`. `npm run preview` открывает собранную версию. `npm test` запускает проверки модели времени и аудиодвижка (Node.js 22+).

## Управление

- Нажмите на клетку, чтобы добавить событие.
- Одна клетка всегда равна одной секунде. Ползунок «Масштаб» приближает и отдаляет шкалу.
- Перетащите событие: перенос и растягивание всегда привязаны к секундам.
- Выберите тип «Звук» и тяните правый край, чтобы изменить длительность.
- Выберите событие для точной настройки начала, длины и повторения.
- Пробел — воспроизведение/пауза; ⌘/Ctrl+Z — отмена; ⌘/Ctrl+Shift+Z — повтор.
- Стрелки перемещают событие в фокусе; Delete удаляет его.
- Нажмите на линейку времени для изменения позиции на паузе.

Таймеры автоматически хранятся в localStorage (`timequence.timers.v2`). Во время воспроизведения оставляйте страницу открытой: мобильные браузеры могут прервать звук в фоне.

## Встроенные звуки

Вкладка «Инструменты» содержит 12 записей реальных инструментов из [VCSL](https://github.com/sgossner/VCSL), лицензия CC0. Файлы поставляются вместе с сайтом, без внешнего аудиосервиса. Уровень выровнен по активной части записи с ограничением пиков; убрана начальная тишина, добавлены плавные края. Два самых длинных звука ограничены 16 секундами. Вся подборка — около 1,4 МБ.

- «Сигнал» играет запись один раз с естественным затуханием, максимум до конца таймера.
- «Звук» повторяет запись до конца события. Короткие ударные повторяются не чаще раза в 0,75 секунды; остальные — с периодом самой записи. Высота звука не меняется. Для редких ударов с точным интервалом используйте «Сигнал» и «Повторить каждые».
- При продолжении после паузы запись возобновляется с нужного места, включая хвост одиночного удара.
- Перед запуском движок загружает и декодирует записи используемых дорожек. До готовности отсчёт не начинается. Неудачную загрузку можно повторить той же кнопкой. Декодированные файлы переиспользуются в пределах открытой страницы.
- Прослушивание в библиотеке можно остановить; выбор другого звука останавливает предыдущий.

Шесть прежних звуков остаются на вкладке «Синтезатор». Сохранённые таймеры сохраняют прежнее звучание; новые таймеры начинают с записи непальского колокольчика.

Источники, лицензия и воспроизводимая подготовка файлов — в [THIRD_PARTY.md](./THIRD_PARTY.md).

Продуктовые решения и дальнейшие этапы — в [PRODUCT.md](./PRODUCT.md).

Таймеры старой версии (`timequence.timers.v1`) автоматически переносятся на фиксированную секундную сетку без изменения событий. Старые данные остаются в браузере как резервная копия. Масштаб сохраняется отдельно для каждого таймера.
