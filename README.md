# Timequence

Браузерный таймер со звуковыми отсечками на дорожках. React, TypeScript, Vite, Web Audio API; сервер и аккаунт не нужны.

При открытии приложения появляется большое приветственное окно поверх редактора. Внутри работает настоящий дзен-режим выбранного таймера: запуск, пауза и громкость общие с редактором. Окно закрывается кнопкой «Открыть редактор», крестиком, Escape или кликом по фону. Повторное открытие через «О приложении» сохраняет таймер и позицию; в мобильной версии эта кнопка находится в меню таймеров и действий. Оформление использует светлую палитру приложения. Прямые адреса `#app`, `#app/breathing`, `#app/tabata` и `#app/new` по-прежнему позволяют открыть редактор без приветствия.

```sh
npm install
npm run dev -- --port 5173
```

`npm run build` проверяет типы и собирает сайт в `dist`. `npm test` запускает проверки модели времени и аудиодвижка (Node.js 22+).

## GitHub Pages

`npm run build:pages` собирает сайт для адреса `https://rusakoff.github.io/timequence/` с нужным префиксом для скриптов, значка и аудиофайлов. Обычная команда `npm run build` остаётся для публикации в корне домена, в том числе на Netlify.

GitHub Pages публикует сайт по адресу [rusakoff.github.io/timequence](https://rusakoff.github.io/timequence/) через workflow **Deploy to GitHub Pages**. Он запускается при каждом push в `main`; его также можно запустить вручную во вкладке **Actions**. Источник публикации в **Settings → Pages** — **GitHub Actions**. См. [документацию GitHub](https://docs.github.com/en/pages/quickstart) и [рекомендации Vite](https://vite.dev/guide/static-deploy.html#github-pages).

## Управление

- Клик по пустой клетке добавляет короткий сигнал без открытия настроек. Клик по заполненной клетке открывает настройки сигнала. Блок показывает его момент, а не длину записи; при крупном шаге соседние блоки сужаются, чтобы не перекрывать друг друга.
- Длительность таймера задаётся минутами и секундами. «Шаг сетки» меняет расстояние между делениями, сохраняя общее время. Если сигналы не попадают точно в новую сетку, редактор показывает будущий сдвиг времени и применяет его только после подтверждения.
- Прогресс показывает общая вертикальная линия. Сначала она движется от левого края сетки до её центра, затем шаги плавно движутся под ней; пауза останавливает движение. В начале слева нет пустого поля.
- Блок можно перенести мышью между позициями и дорожками. Его длина не редактируется.
- Каждый сигнал звучит один раз, не дольше 3 секунд и не дольше оставшегося времени таймера.
- Клик по значку или названию дорожки открывает её настройки. Название редактируется в этой панели: Enter и выход из поля сохраняют, Escape отменяет.
- В свойствах дорожки можно выбрать звук, цвет и громкость. Смена звука сохраняет выбранный цвет и пользовательское имя.
- Клик по событию открывает карточку с точным временем сигнала, звуком, цветом и повтором. Время вводится как `мм:сс` или число секунд; интервал повторов задаётся в секундах.
- Карточка закрывается кликом вне неё, крестиком или Escape. По Escape фокус возвращается к событию. Она следует за блоком при прокрутке и не сдвигает сетку.
- «Дзен-режим» показывает увеличенный сегмент между сигналами: название и цвет текущей дорожки, указатель прогресса, время до следующего события и следующее действие. Доступны полный экран, пауза и выключение звука с возвратом прежней громкости. Открытие и закрытие не прерывают таймер.
- В новых таймерах есть «Тик · 1 с»: отдельная линейка с черточками по реальным секундам, независимо от шага. Кнопка звука работает и во время воспроизведения. Тики не меняют этапы в дзен-режиме.
- Пробел — запуск/пауза; ⌘/Ctrl+Z — отмена; ⌘/Ctrl+Shift+Z — повтор.
- Стрелки перемещают выбранную отсечку; Delete удаляет её. Клик по линейке меняет позицию на паузе.

В стартовом наборе восемь практических таймеров: тренировка 60/30, дыхание 4–7–8, движения глаз, табата 20/10, чистка зубов, круговая тренировка, растяжка по сторонам и запоминание по карточкам. Дорожки названы по действиям. Например, дыхание содержит сигналы в 0, 4 и 11 секунд каждого 19-секундного цикла. Полный состав, длительности и источники — в [EXAMPLES.md](./EXAMPLES.md).

## Звуки и хранение

В библиотеке — все 78 звуков набора **Glass** из [uisfx](https://uisfx.com). Есть русские названия и поиск по русскому или английскому названию. Другие наборы недоступны. Секундная отсечка использует короткий Glass `typing`.

Звуки синтезируются локально через `createRecipe("glass", cue)` и `renderRecipe`, без загрузки аудиофайлов. Готовые стереобуферы переиспользуются для предпрослушивания и таймера; расписание остаётся на аудиочасах Web Audio. Каждый сигнал звучит один раз, включая один цикл шести ритмических звуков. Максимум — 3 секунды или оставшееся время таймера. Пауза и продолжение сохраняют позицию внутри сигнала.

После обновления `uisfx` выполните `npm run sounds:metadata`, чтобы обновить длительности для подсветки сигналов. `npm test` сверяет их с фактическим рендером всех 78 звуков.

Таймеры автоматически хранятся в localStorage (`timequence.timers.v11`, объект `{ version: 11, timers }`). Данные v1–v4 мигрируют: изменённые и собственные таймеры сохраняют ID, дорожки и события; прежние длительности и типы блоков удаляются. Нетронутые старые демонстрации заменяются новым набором. Старые ключи остаются резервной копией. В v7 по запросу удалены примеры фокуса, чая, медитации, уборки, выступления и «Тихая последовательность». При переходе из v5–v6 остальные таймеры сохраняются. При переходе в v8 добавляются только три согласованных новых примера. Для старых таймеров подбирается общий шаг без переноса сигналов; их ID сохраняются. В v9 ко всем таймерам добавляются две дорожки секундомера без изменения существующих событий. Их отключение и удаление сохраняются. После перехода удалённые примеры не появляются снова. В v10 удалён пятисекундный тик. В v11 старые звуки автоматически заменяются на Glass с сохранением ID, названий, цветов, громкости, отключённых дорожек и времени событий. Ключ v10 остаётся резервной копией; удалённые дорожки и таймеры не восстанавливаются.

Во время воспроизведения оставляйте страницу открытой: мобильные браузеры могут прервать звук в фоне. Офлайн-режим, импорт/экспорт и синхронизация пока не реализованы.

Источники и лицензии звуков — в [THIRD_PARTY.md](./THIRD_PARTY.md). Продуктовые решения — в [PRODUCT.md](./PRODUCT.md). Выполненные проверки — в [TESTING.md](./TESTING.md).

Кнопки «Дзен» и «Таймер» находятся рядом с Play и сразу запускают выбранный вид. При уже работающем таймере смена вида сохраняет позицию. В дзен-режиме крупный отсчёт сопровождается названием следующего действия.
