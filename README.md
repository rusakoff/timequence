# Timequence

Браузерный таймер со звуковыми отсечками на дорожках. React, TypeScript, Vite, Web Audio API; сервер и аккаунт не нужны.

```sh
npm install
npm run dev -- --port 5173
```

`npm run build` проверяет типы и собирает сайт в `dist`. `npm test` запускает проверки модели времени и аудиодвижка (Node.js 22+).

## GitHub Pages

`npm run build:pages` собирает сайт для адреса `https://rusakoff.github.io/timequence/` с нужным префиксом для скриптов, значка и аудиофайлов. Обычная команда `npm run build` остаётся для публикации в корне домена, в том числе на Netlify.

Для публикации откройте в репозитории **Settings → Pages**, выберите **GitHub Actions** как источник, затем запустите вручную workflow **Deploy to GitHub Pages** во вкладке **Actions**. Workflow не запускается на каждый push, пока Pages не включён. Репозиторий сейчас приватный: для GitHub Pages в приватном репозитории GitHub требует подходящий платный тариф; с GitHub Free репозиторий должен быть публичным. Сам сайт Pages обычно доступен всем даже при приватном репозитории. См. [документацию GitHub](https://docs.github.com/en/pages/quickstart) и [рекомендации Vite](https://vite.dev/guide/static-deploy.html#github-pages).

## Управление

- Клик по клетке добавляет короткий сигнал. Блок показывает его момент, а не длину записи; при крупном шаге соседние блоки сужаются, чтобы не перекрывать друг друга.
- Длительность таймера задаётся минутами и секундами. «Шаг сетки» меняет расстояние между делениями, сохраняя общее время. Если сигналы не попадают точно в новую сетку, редактор показывает будущий сдвиг времени и применяет его только после подтверждения.
- Прогресс показывает общая вертикальная линия. Сначала она движется от левого края сетки до её центра, затем шаги плавно движутся под ней; пауза останавливает движение. В начале слева нет пустого поля.
- Блок можно перенести мышью между позициями и дорожками. Его длина не редактируется.
- Каждый сигнал звучит один раз, не дольше 3 секунд и не дольше оставшегося времени таймера.
- Клик по значку или названию дорожки открывает её настройки. Название редактируется в этой панели: Enter и выход из поля сохраняют, Escape отменяет.
- В свойствах дорожки можно выбрать звук, цвет и громкость. Смена звука сохраняет выбранный цвет и пользовательское имя.
- Клик по событию открывает карточку с точным временем сигнала, звуком, цветом и повтором. Время вводится как `мм:сс` или число секунд; интервал повторов задаётся в секундах.
- Карточка закрывается кликом вне неё, крестиком или Escape. По Escape фокус возвращается к событию. Она следует за блоком при прокрутке и не сдвигает сетку.
- «Дзен-режим» показывает увеличенный сегмент между сигналами: название и цвет текущей дорожки, указатель прогресса, время до следующего события и следующее действие. Доступны полный экран, пауза и выключение звука с возвратом прежней громкости. Открытие и закрытие не прерывают таймер.
- В новых таймерах есть «Тик · 1 с»: отдельная линейка с черточками по реальным секундам, независимо от шага. Кнопка звука работает и во время воспроизведения. Тики не меняют этапы в дзен-режиме.
- Пробел — запуск/пауза; ⌘/Ctrl+Z — отмена; ⌘/Ctrl+Shift+Z — повтор.
- Стрелки перемещают выбранную отсечку; Delete удаляет её. Клик по линейке меняет позицию на паузе.

В стартовом наборе восемь практических таймеров: тренировка 60/30, дыхание 4–7–8, движения глаз, табата 20/10, чистка зубов, круговая тренировка, растяжка по сторонам и запоминание по карточкам. Дорожки названы по действиям. Например, дыхание содержит сигналы в 0, 4 и 11 секунд каждого 19-секундного цикла. Полный состав, длительности и источники — в [EXAMPLES.md](./EXAMPLES.md).

## Звуки и хранение

12 записей инструментов из [VCSL](https://github.com/sgossner/VCSL), лицензия CC0, поставляются вместе с сайтом. Подборка занимает около 543 КиБ. Начальная тишина удалена, громкость выровнена, длинные записи сокращены до 3 секунд с плавным затуханием. Пользовательские файлы пока не загружаются.

Восемь звуков на вкладке «Синтезатор» также играют однократно. Звуковой движок дополнительно ограничивает любой источник тремя секундами, в том числе при прослушивании. Перед запуском записи загружаются и декодируются; при ошибке загрузку можно повторить. Пауза и продолжение сохраняют позицию в коротком хвосте сигнала.

Таймеры автоматически хранятся в localStorage (`timequence.timers.v9`, объект `{ version: 9, timers }`). Данные v1–v4 мигрируют: изменённые и собственные таймеры сохраняют ID, дорожки и события; прежние длительности и типы блоков удаляются. Нетронутые старые демонстрации заменяются новым набором. Старые ключи остаются резервной копией. В v7 по запросу удалены примеры фокуса, чая, медитации, уборки, выступления и «Тихая последовательность». При переходе из v5–v6 остальные таймеры сохраняются. При переходе в v8 добавляются только три согласованных новых примера. Для старых таймеров подбирается общий шаг без переноса сигналов; их ID сохраняются. В v9 ко всем таймерам добавляются две дорожки секундомера без изменения существующих событий. Их отключение и удаление сохраняются. После перехода удалённые примеры не появляются снова.

Во время воспроизведения оставляйте страницу открытой: мобильные браузеры могут прервать звук в фоне. Офлайн-режим, импорт/экспорт и синхронизация пока не реализованы.

Источники и подготовка записей — в [THIRD_PARTY.md](./THIRD_PARTY.md). Продуктовые решения — в [PRODUCT.md](./PRODUCT.md). Выполненные проверки — в [TESTING.md](./TESTING.md).

Кнопки «Дзен» и «Таймер» находятся рядом с Play и сразу запускают выбранный вид. При уже работающем таймере смена вида сохраняет позицию. В дзен-режиме крупный отсчёт сопровождается названием следующего действия.
